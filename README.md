## ✨ Características Principales

- ⚡ **Dynamic Schema Engine:** Generación automática de UI y validaciones a partir de `information_schema`.
- 🛡️ **Protección de Tablas:** Sistema de importación/exportación con filtro para tablas core (`users`, `roles`, etc.).
- 🎨 **Tema Dinámico:** Soporte nativo para modo oscuro/claro y persistencia local.
- 📦 **Mapeo de Enums:** Detección automática de campos de tipo `enum` mapeados a selects interactivos.

---

## 🛠️ Stack Tecnológico

- **Backend:** Laravel 13
- **Frontend:** React + Inertia.js + TypeScript
- **Estilos:** Tailwind CSS + Shadcn UI
- **Base de Datos:** MySQL (InnoDB)
